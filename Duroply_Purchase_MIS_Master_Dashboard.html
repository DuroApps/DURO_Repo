🐙 GitHub Snapshot Sync

Instead of pulling all rows from Supabase on every visit, this suite can read a cached purchase_mis_suite_snapshot.json file from a GitHub repo first (instant load across every page in the suite), then check Supabase in the background and flag it here if the row count has moved on. Reading the snapshot needs just Owner/Repo/Branch/Path (public repo) — only saving a new snapshot needs a Personal Access Token.
